Bayle 6: a new app, rebuilt on Tauri, with the same engine as Bayle 5.0.2. Windows only for now.

Already on 6.0.0-beta.1? Bayle offers this update by itself; nothing else to do. New since beta.1: the app ships its license and third-party notices.

## Coming from Bayle 5?

Bayle 6 is a new app and installs fresh. Uninstall Bayle 5 first: your mods, profiles, saves and Bayle 5's own data stay on your PC. Then install Bayle 6. From 6.0 on, Bayle updates itself.

1. Close Bayle 5.
2. Uninstall it: Settings › Apps › Installed apps › Bayle (version 5) › Uninstall.
3. Run `Bayle_6.0.0_x64-setup.exe` below.
4. In the welcome screens, check where the game is. Profiles in me3's usual folder show on Mods by themselves.

To keep Bayle 5's settings, save backups, Library and Activity, copy them over right after installing, before you change anything in Bayle 6:

1. Close Bayle 6.
2. Back up `%LOCALAPPDATA%\RoundtableSouls` somewhere safe.
3. Rename `%LOCALAPPDATA%\io.github.carlomos7.bayle` to `io.github.carlomos7.bayle.old`.
4. Copy `%LOCALAPPDATA%\RoundtableSouls` and name the copy `io.github.carlomos7.bayle`. Leave out the folders `cache`, `temp`, `updates` and `webview2`, and any `.lock` files.
5. Open Bayle 6 and skip the welcome screens.

## If setup stops at the WebView2 step

Bayle needs Microsoft Edge WebView2 Runtime, which Windows 11 includes and Windows Update adds to Windows 10. If setup can't install it, it stops before installing Bayle and nothing of yours changes. Install the Evergreen Bootstrapper (or, offline, the Evergreen Standalone Installer x64) from [Microsoft's WebView2 page](https://developer.microsoft.com/microsoft-edge/webview2/), then run Bayle's setup again.

## Good to know

- Windows SmartScreen may warn on the first install: the installer is not code-signed yet. Choose More info, then Run anyway.
- When uninstalling Bayle 6, leave "Delete the application data" unticked unless you want its settings, save backups and Library gone for good.
- Bayle 5 offers this release as an update, but it can't install it ("This release has no signed update feed"): uninstall Bayle 5 and use the setup above.
- Older versions are no longer downloadable here. Their source stays in this repository: Bayle 5 on the `legacy/qt-desktop` branch, every version under its `v*` tag.
- Linux and the Steam Deck come later.
